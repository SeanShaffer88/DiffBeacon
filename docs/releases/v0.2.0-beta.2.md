# DiffBeacon 0.2.0 Beta 2

## What's new

- **Scroll through large comparisons with less delay.** DiffBeacon moves aligned panes together, then applies inline highlights to the visible text. If the exact alignment budget is exceeded, the panes scroll independently.
- **Start maximized and restore to a resizable window.** The restored window fits smaller work areas when they can accommodate its minimum size. The results pane leaves room for a complete row in the verified layouts.
- **Choose a workspace appearance.** Settings → Appearance offers System, Light, and Dark, with independent Crimson, Blue, and Teal accents. Dark remains the default. DiffBeacon saves explicit appearance choices in `data/appearance.json` beside the app.
- **Find commands from the keyboard.** Press **Ctrl+K** or choose **Commands** to search actions available in the current comparison session.

## Run the beta

Install the .NET 10 Desktop Runtime for Windows x64 if needed. Extract the entire Windows x64 ZIP to a writable folder and run `DiffBeacon.exe` from there. The portable build is unsigned and requires the installed Desktop Runtime.

To carry appearance settings between portable copies, copy `data/appearance.json` beside the new executable using the same folder structure. The five reusable modules use version `0.2.0-beta.2` and can be consumed from a local package feed. See the [module guide](https://github.com/SeanShaffer88/DiffBeacon/blob/v0.2.0-beta.2/docs/MODULES.md).

## Known limits

Toggling Word Wrap between typing and Undo can lose native typing undo history. The workspace needs more room at larger text sizes. Live Windows high-contrast switching, physical mixed-DPI displays, and screen-reader behavior remain open checks.

Text alignment and retained results have explicit budgets. Folder and table comparisons are read-only. See [usage and hard limits](https://github.com/SeanShaffer88/DiffBeacon/blob/v0.2.0-beta.2/docs/USAGE.md), the [feature matrix](https://github.com/SeanShaffer88/DiffBeacon/blob/v0.2.0-beta.2/docs/FEATURES.md), and [verification evidence](https://github.com/SeanShaffer88/DiffBeacon/blob/v0.2.0-beta.2/docs/VERIFICATION.md).
