# v0.2.0-beta.1

First public beta for testing. Feature completeness, stable readiness and full replacement readiness remain outstanding.

## Highlights

- Native C# / .NET 10 Windows Forms interface with VaporGrid styling, comparison tabs and side-by-side or stacked text editors.
- Two-way text editing, bounded Line/Word/Character highlighting, synchronized scrolling, difference navigation and explicit selection/block merges.
- Base/Local/Remote review with automatic disjoint edits, explicit conflict choices and guarded merged output.
- Recursive content-based folder comparisons with filters, full-file streamed binary checks and positional CSV/TSV comparison.
- Explicit Unicode-preserving saves, stale-file checks, atomic replacement and retained backups, plus local sessions, HTML reports and CLI checks.

## Run the beta

Use Windows x64 with the .NET 10 Desktop Runtime for Windows x64. Extract the entire Windows x64 ZIP and run DiffBeacon.exe from the extracted directory. The portable package is unsigned and framework-dependent.

## Known issues and limits

- Toggling the native RichTextBox WordWrap property between typing and Undo can lose that typing undo history. Orientation switching has separate passing checks with wrap already enabled or disabled.
- Physical DPI/text scaling, live high contrast and full accessibility acceptance are incomplete.
- Text editing/alignment, retained results and traversal have explicit budgets. Folder and table views are read-only. Document parsers, folder synchronization, three-way sessions and Git mergetool remain planned.
- Overwriting an existing file retains a sibling backup. Mixed-newline text saves are refused. Review [usage and hard limits](../USAGE.md) and the [feature matrix](../FEATURES.md).
